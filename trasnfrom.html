摘要，图形学入门

Jan 31, 2022

以下内容为 Games 101 网课的学习笔记。 虽主要是摘抄与碎碎念，但也记录了初探图形学世界的足迹。 在此稍作润色，以此证明，对于这片未知的领域，我曾来过。

图形学

以下为 Games 101 网课笔记。

由于大学没有选修此门功课，工作后深感图形学之重要，遂在此补课拜读。

变换（Transform）

作为一名前端开发者，对于 CSS Transform 可谓非常熟悉。伸缩（Scale）、旋转（Rotate）、平移（Translate）、倾斜（Skew/Shear）等，本质上均可通过向量 + 矩阵的乘法来表述，即变换矩阵（Transformation Matrix）。

为什么要统一为矩阵？答：统一且高效。通过矩阵乘法，可以将多次变换合并为一次运算，极大地提升了计算效率。

光栅化（Rasterization）

将矢量图形数据投影到屏幕坐标（只是坐标的变换，还未真正显示到屏幕像素上）的过程，称为光栅化（Rasterization）。

众所周知，屏幕由像素点组合而成，像素点最小单位为 1，是不连续 / 离散的。但矢量图形（如三角形）在数学上是连续的。从连续（模拟信号/数据）到不连续（数字信号/实际显示），需要经过「采样」（Sampling）。

采样，必定存在信息的丢失。最常见的现象就是「锯齿」（Aliasing）。作为一名游戏玩家，对抗锯齿（Anti-Aliasing）不可谓不熟悉。（GTMD 的显卡矿潮，害得老子当年没得 3060Ti Van ♂ 游戏，只能学图形学解闷。）

课程讲述的抗锯齿的方法主要有三：

  1. 先「模糊」再「采样」：称为「多重采样抗锯齿」（Multisample anti-aliasing）。很容易理解，模糊就是将特征从一个点扩散到周围，做到你中有我，我中有你，从而软化边缘。
  2. 从上一帧查找灵感：如「快速近似抗锯齿」（Fast approximate anti-aliasing）、时间抗锯齿（Temporal anti-aliasing）。MSAA 是在同一时间、单一位置的空间模糊；而 TAA 是利用时间维度，混合上一帧的信息来实现平滑。
  3. 根据经验，去猜（AI）：2022 年，涉及“猜”的东西，第一反应便是「机器学习」。如 NVIDIA 的 DLSS、AMD 的 FSR、以及 Intel 的 XeSS。（往自己脸上贴金之：我有一位林姓同学，港大博士毕业，两年三篇次顶会一作，腾讯技术大咖专项 SSSP，从事 2D → 3D 建模还原，用的也是机器学习 + 几何算法。）

采样的另一个弊端是：摩尔纹（Moiré pattern）。课程中对于摩尔纹产生原因的解释是「采样的速度跟不上信号的变化」。目前的理解是：当采样的频率和图像的频率发生干涉（如正交投影下倾斜的单元网格），就会产生额外的低频干扰图案。

在此简单带过一个概念：深度缓冲（Z-buffer）。它用于解决三维坐标投影到二维平面时，不同深度的点在同一像素位置的遮挡关系（可见性）问题。

着色（Shading）

顾名思义，就是对一个点上颜色。看似非常简单，但稍深入了解，可谓技巧满满。因为不同的着色算法可以模拟不同的光照和材质！同一个 3D 模型，应用不同的 Shader，既可表现为冰，又可表现为火。

推荐阅读开源书籍 The Book of Shader（介绍了 GLSL 着色器语言）。

对于光照，常见的是应用布林-冯反射模型（Blinn-Phong），它将光照分解为三个分量：

  • **环境光 (Ambient)**：基础底色。
  • **漫反射 (Diffuse)**：受光面亮度。
  • **高光 (Specular)**：镜面反射亮点。

截止于此，一个基本的实时渲染管线（Pipeline）大体为：顶点处理 -> 三角化 -> 光栅化 -> 着色 -> 输出。

贴图（Texture Mapping）

Long Long Ago，自学 Blender 和 Three.js 时，对贴图略知一二。简单来说，很多酷炫的细节如果全部用几何体建模，面数会爆炸，GPU 算力遭不住。如果能提前画在图片（2D）上，再通过 UV 坐标映射到物体（3D）表面，就能极大地节省算力。「预烘焙」在游戏中是常见的优化手段。

最常见的贴图方式便是 UV 贴图（UV mapping）。
纹理采样时会遇到放大缩小的问题，涉及不同的插值方式：

  • 双线性插值（Bilinear）
  • 双三次插值（Bicubic）
  • Mipmap：解决远距离纹理产生的摩尔纹和性能浪费。

单独提一下「各向异性过滤（Anisotropic filtering）」。这项技术能让倾斜视角的远处纹理更加清晰，减少模糊。

几何（Geometry）

这部分主要讲述如何用数据表达自然界的物体。

  • 凹凸感模拟：法线贴图（Normal Map）、位移贴图（Displacement Map）。
  • 几何表示：
    • 隐式几何：代数公式、距离函数（SDF）、分形。
    • 显式几何：点云、多边形网格（Mesh）。
  • 曲线与曲面：贝塞尔曲线（Bézier Curve）、样条曲线（Spline）。
  • 网格处理：细分（Loop, Catmull-Clark）、简化、正则化。

光线追踪（Ray Tracing）

光线追踪，通过跟踪与光学表面发生交互作用的光线从而得到光线经过路径的模型。

如果说光栅化是“将几何体投影到屏幕”，那么光线追踪就是“从眼睛发出光线去寻找几何体”。其运算本质上是海量的射线与场景的碰撞检测。

为了加速碰撞检测，引入了包围盒（Bounding Volume）的概念：

  • 简单性：形状简单（如球、立方体），计算快。
  • 紧密性：尽可能贴近物体，减少误判。

最常见的是 AABB 包围盒（Axis-aligned bounding box，轴对齐包围盒）。

进一步加速需要空间划分（Spatial Partitioning）数据结构：

  • 八叉树（Oct-Tree）：将空间均匀切分。
  • BSP-Tree：二叉空间分割。
  • KD-Tree：每次沿一个轴切分，常用于静态场景。
  • BVH（Bounding Volume Hierarchies）：基于物体划分而非空间划分，是现代光追的主流选择。

光线追踪在物理上的数学描述：

  1. 辐射度量学：引入 BRDF（双向反射分布函数），基于物理（PBR）地描述光与物质的交互。
  2. 渲染方程：利用泰勒展开近似，n=0 是自发光，n=1 是直接光照，n>1 是间接光照（全局光照 GI）。
  3. 蒙特卡洛积分：利用概率密度函数（PDF）对渲染方程进行数值求解，解决复杂的积分计算。

材质与外观（Material）

  • 材质属性：反射率、折射率、微表面模型（Microfacet）。
  • 光线传播路径：
    • 蒙特卡洛估计：无偏（Unbiased） vs 有偏（Biased）。
    • 双向路径追踪（BDPT）。
    • 光子映射（Photon Mapping）。
  • 外观建模：
    • 非表面建模：头发、毛发、颗粒介质（云、雾）。
    • 程序化纹理：噪声函数（Perlin Noise）。

其它

课程最后做了一些概念的拓展：

  • 相机原理：小孔成像、光圈（景深）、快门（动态模糊）、ISO（噪点）。
  • 光场（Light Field）：全光函数，记录空间中所有位置、所有方向的光线信息。
  • 动画（Animation）：
    • 物理模拟：弹簧质点系统、有限元分析（FEM）。
    • 运动学：正向（FK）、逆向（IK）。
    • 动作捕捉。

推荐后续学习：Games103 基于物理的计算机动画入门。

总结

图形学是计算机科学、数学、物理学、艺术等多学科交叉融合的领域。不仅需要扎实的数学功底（线性代数、微积分、概率论），还需要对物理世界有敏锐的观察力。

虽然作为前端开发，日常工作中极少直接写 Shader 或手撸光追算法，但理解了这些底层原理，对于 WebGL/WebGPU 的开发，甚至 CSS 渲染性能的优化，都有着降维打击般的帮助。
